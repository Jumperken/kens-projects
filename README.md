# Ken’s Projects

A static personal website with a homepage and eight sections: Engineering, Maine Cabin, ATVs & Snowmobiles, Sailing, 3D Printing, Home Projects, Golf, and Travel.

GitHub Pages publishes this repository from the `main` branch and `/ (root)` folder. The public address is shown in **Settings → Pages** after deployment completes.

## Editing the website

Each HTML page is self-contained: its styles, small keyboard-navigation script, and illustrated cover are embedded. This avoids separate asset uploads. No build tools, paid dependencies, external fonts, or image services are required.

Open a category’s HTML file and edit its project text, photo placeholders, or file links. Commit changes to `main` to publish updates. Keep the existing filenames so the navigation continues to work. Cover artwork is illustrative; it does not represent Ken’s actual possessions or completed projects.

The project notes template is included as an embedded text download. The PDF, photo, and video areas are clearly marked placeholders for Ken’s future content.

An editable package with separate HTML, CSS, JavaScript, and image files was also supplied alongside this website. That package can replace these self-contained pages as a complete upload; preserve its `assets` and `files` folders when doing so.
